# LedgerLine – Secure Money Transfer and Ledger Management System

Please see the complete application in the [`LedgerLine`](./LedgerLine) directory.

## Quick Start
```bash
cd LedgerLine
npm install
npm run seed
npm start
```

## Running Automated Tests
```bash
cd LedgerLine
npm test
```
